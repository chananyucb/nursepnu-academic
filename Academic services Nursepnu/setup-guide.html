สมัคร สร้าง Project รัน SQL ใส่ Key Deploy
1
สมัครบัญชี Supabase (ฟรี)
ใช้บัญชี GitHub หรืออีเมลก็ได้ ไม่ต้องใส่บัตรเครดิต
  • เปิดเบราว์เซอร์ไปที่ supabase.com
  • กดปุ่ม "Start your project" หรือ "Sign Up"
  • เลือก Sign in with GitHub (แนะนำ) หรือใช้อีเมล
  • ยืนยันอีเมล จากนั้น dashboard จะเปิดขึ้นมา

สร้าง Project ใหม่
ตั้งชื่อ เลือก Region ใกล้ที่สุด และตั้งรหัสผ่านฐานข้อมูล
  • กด "New Project" ใน Supabase Dashboard
  • ตั้งชื่อ Project เช่น nursepnu-academic
  • เลือก Region: Southeast Asia (Singapore)
  • ตั้งรหัสผ่านฐานข้อมูล (จด/เก็บไว้ แต่เราไม่ได้ใช้โดยตรง)
  • กด "Create new project" — รอ ~1 นาที

3
รัน SQL สร้างตาราง
Copy SQL ด้านล่าง → วางใน Supabase SQL Editor → Run
  • ในหน้า Supabase Project กดเมนู "SQL Editor" (ไอคอนรูปรหัสด้านซ้าย)
  • กด "New query"
  • Copy โค้ดด้านล่าง ทั้งหมด แล้ว Paste ลงในช่อง
  • กดปุ่ม "Run" (หรือ Ctrl+Enter)
  • จะเห็นข้อความ "Success. No rows returned"
SQL — รัน 1 ครั้ง ใน Supabase SQL Editor 
-- =====================================================
-- Nursepnu Academic Services — Supabase Schema
-- วาง SQL นี้ใน SQL Editor แล้วกด Run (รันครั้งเดียว)
-- =====================================================

-- ตารางโครงการบริการวิชาการ
CREATE TABLE IF NOT EXISTS projects (
  id                 TEXT          PRIMARY KEY,
  year               INTEGER       NOT NULL,
  name               TEXT          NOT NULL,
  category           TEXT          DEFAULT 'academic',
  duration           TEXT,
  target             TEXT,
  recipients         INTEGER       DEFAULT 0,
  budget             NUMERIC       DEFAULT 0,
  income             NUMERIC       DEFAULT 0,
  deduct_university  NUMERIC       DEFAULT 0,
  deduct_faculty     NUMERIC       DEFAULT 0,
  actual             NUMERIC       DEFAULT 0,
  remaining          NUMERIC       DEFAULT 0,
  owner              TEXT,
  status             TEXT          DEFAULT 'plan',
  created_at         TIMESTAMPTZ   DEFAULT NOW()
);

-- ตารางค่าวิทยากรภายนอก
CREATE TABLE IF NOT EXISTS speaker_records (
  id                 TEXT          PRIMARY KEY,
  seq                INTEGER,
  first_name         TEXT,
  last_name          TEXT,
  topic              TEXT,
  date               TEXT,
  venue              TEXT,
  amount             NUMERIC       DEFAULT 0,
  deduct5            NUMERIC       DEFAULT 0,
  deduct10           NUMERIC       DEFAULT 0,
  total_withholding  NUMERIC       DEFAULT 0,
  net_amount         NUMERIC       DEFAULT 0,
  is_paid            BOOLEAN       DEFAULT false,
  remark             TEXT,
  created_at         TIMESTAMPTZ   DEFAULT NOW()
);

-- เปิด Row Level Security
ALTER TABLE projects        ENABLE ROW LEVEL SECURITY;
ALTER TABLE speaker_records ENABLE ROW LEVEL SECURITY;

-- อนุญาตให้ทุกคนอ่านได้ (สาธารณะ)
CREATE POLICY "public_read_projects"
  ON projects FOR SELECT USING (true);

CREATE POLICY "public_read_speakers"
  ON speaker_records FOR SELECT USING (true);

-- อนุญาตให้ Admin เขียนได้ (ผ่าน anon key)
CREATE POLICY "admin_write_projects"
  ON projects FOR ALL USING (true);

CREATE POLICY "admin_write_speakers"
  ON speaker_records FOR ALL USING (true);
✅
เมื่อ Run สำเร็จ จะเห็น "Success. No rows returned" ที่ด้านล่างของ SQL Editor
4
Copy API Keys ใส่ไฟล์ supabase-config.js
ไปที่ Settings → API → แล้ว copy URL และ anon key
  • ใน Supabase Project กดเมนู "Settings" (ไอคอนฟันเฟือง)
  • เลือก "API" ในเมนูด้านซ้าย
  • Copy Project URL (เช่น https://xxxx.supabase.co)
  • Copy anon / public key (ข้อความยาวๆ ใต้หัวข้อ Project API keys)
  • เปิดไฟล์ supabase-config.js ในโปรเจกต์ แล้วแทนที่ค่าทั้งสอง
supabase-config.js — แก้ไขค่าทั้งสอง 
// supabase-config.js
// แก้ค่าด้านล่างด้วยข้อมูลจาก Supabase Settings → API

window.SUPABASE_URL      = 'https://YOUR_PROJECT_ID.supabase.co';
window.SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';
🔑
anon key ปลอดภัยที่จะใส่ใน frontend — เป็น key สาธารณะที่ออกแบบมาให้ใช้ใน Browser ค่าลับจริงๆ คือ service_role key ซึ่งห้ามใส่ใน code อย่างเด็ดขาด
5
Upload ขึ้น GitHub Pages
อัปโหลดไฟล์ทั้งหมดขึ้น GitHub repo แล้วเปิด Pages
  • ไปที่ github.com → กด "New repository"
  • ตั้งชื่อ เช่น nursepnu-academic → Public → Create
  • ใน repository กด "uploading an existing file"
  • Download โปรเจกต์ จากนี้ (ปุ่มด้านล่าง) → แตกไฟล์ → ลากไฟล์ทั้งหมดอัปโหลด
  • กด "Commit changes"
  • ไปที่ Settings → Pages → Source: "Deploy from a branch" → Branch: main → กด Save
  • รอ ~2 นาที จะได้ URL เช่น https://username.github.io/nursepnu-academic/
🌐
หลังจาก GitHub Pages พร้อม เปิดลิงก์ของคุณ หน้าสาธารณะ (public.html) และ Admin (index.html) จะใช้งานได้จากทุกเครื่อง ข้อมูลแชร์กันจริง!
